# 灰色リバーシ

一手ごとに石の色が薄れていき、やがて盤上の石はすべて同じ灰色になる。
どの石が自分のものか、覚えていられますか？ ── **記憶力で戦うリバーシ**です。

## 遊び方

1. 設定を選んで「対局開始」を押します。
2. ルールは普通のリバーシと同じです。黒が先手です。
3. 1手目は白と黒がはっきり見えますが、手が進むごとに両方の色が灰色に近づきます。
4. 指定した手数で、白と黒の区別が完全につかなくなります。そこからは記憶だけが頼りです。
5. どちらも置けなくなると終局です。石の色が元に戻り、勝敗が表示されます。

石の数は終局まで表示されません。何枚返したかのメッセージと、石が返る動きが手がかりになります。

## 設定

| 項目 | 選択肢 | 内容 |
| --- | --- | --- |
| 完全に灰色になる手数 | 20手目 / **30手目** / 40手目 | 小さいほど早く見えなくなり、難しくなります |
| 対戦相手 | **ふたりで** / コンピュータ(白) | コンピュータは盤面を忘れないので手強いです |
| 置けないマスを選んだら | **やり直せる** / 手番を失う | 「手番を失う」を選ぶと、お手つきで相手の番になります |
| 置けるマスの表示 | **なし** / あり(やさしい) | 慣れるまでの練習用です |

太字が初期設定です。

### その他の機能

- **答え合わせ**: 対局の途中でも、2回押すと対局を終えて石の色を戻せます。
- **お手つきの記録**: 置けないマスを選んだ回数を、黒と白それぞれ記録します。
- **パスの告知**: 置けるマスがない場合は自動でパスになり、メッセージで知らせます。

<details>
<summary>🌈 裏モード(ネタバレ注意)</summary>

設定画面でタイトル横の灰色の石を押すと、石がひっくり返って **ゲーミングリバーシ** に切り替わります。

- ルールは同じです。石は灰色にならず、だんだん虹色に光っていきます。
- 指定の手数で、すべての石が同じ虹色に輝きます。
- もう一度石を押すと、元に戻ります。
- 対局中は切り替えられません。設定画面か終局後に切り替えてください。
- パソコンでは、隠しコマンドでも切り替えられます。

</details>

## 起動方法

`index.html` をブラウザで開くだけで遊べます。インストールやビルドは必要ありません。

### GitHub Pages で公開する場合

1. このリポジトリを GitHub に push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」にして、ブランチ `main`、フォルダ `/ (root)` を選んで保存します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります。

## 技術メモ

- 素の HTML / CSS / JavaScript だけで作っていて、ライブラリは使っていません。
- フォントは Google Fonts(Shippori Mincho、DotGothic16)を読み込みます。オフラインのときは端末のフォントで表示されます。
- スマホとパソコンの両方の画面幅に対応しています。
- 動きを減らす設定(prefers-reduced-motion)の端末では、アニメーションを控えめにします。
